# Mini Feed

一个用纯 HTML + CSS + 原生 JavaScript 实现的轻量个人动态分享应用。零依赖、零构建，直接打开页面即可使用；所有数据保存在浏览器 Local Storage 中，无需账号或后端服务。

## 功能

- 发布动态：输入文字后点击「发布」，或使用 `Ctrl / Cmd + Enter` 快捷发布
- 查看动态：时间线按发布时间倒序展示，含本地时间戳
- 本地持久化：刷新或关闭页面后数据仍然存在
- 字数限制：单条最多 280 字，实时显示剩余字数
- 空状态：无内容时给出友好提示

## 使用

直接双击 `index.html` 用浏览器打开即可。若希望以本地服务方式访问：

```bash
# 任选其一，进入项目目录后执行
python -m http.server 8000
npx serve .
```

然后访问 `http://localhost:8000`。

## 说明

- 数据键名为 `minifeed_posts`，仅对当前浏览器、当前站点有效；清理浏览器站点数据会一并清除。
- 渲染使用 `textContent`，避免内容中的 HTML 被解析执行。
- 本项目仅实现最小可用的发布与查看流程，不含登录、评论、点赞等功能。
